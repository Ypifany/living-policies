# living-policies

A template for clear, useful cybersecurity policies.

## Ypifany: Policies that help the work happen

A public working demonstration of policies organized around Ypifany's services and the results clients come to receive. It shows how decisions, professional contributions, and observations can help working arrangements evolve.

Open `index.html` in a browser to explore the demonstration locally. The page is self-contained and requires no installation or external dependencies.

- **Our menu:** service areas, supporting draft policies, and contributions to the client result.
- **Policies in use:** three illustrative situations with starting arrangements, feedback, proposed revisions, and different contributions.
- **Level 1 reference:** 15 supporting safeguarding references, each marked **Not assessed**.

The policies are working drafts. The situations illustrate possible changes; they do not report client outcomes. The Level 1 view is a supporting reference, not an assessment or a claim of implemented safeguards, CMMC status, or contract eligibility.

This directory contains only the public demonstration and this README. Private assessment notes, client information, current account settings, and recovery details are excluded.
